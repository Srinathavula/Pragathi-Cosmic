# Pragathi Cosmic — AI-Powered Website & Siri Voice Assistant

An interactive, cosmic-themed website featuring **Siri, a personalized AI voice assistant**, designed to provide natural conversational assistance through a modern web experience.

## Live Demo

🌐 https://pragathi-cosmic.hatchable.site/

## Project Overview

Pragathi Cosmic combines a modern website UI with a conversational AI assistant. Siri is configured to support everyday questions, short summaries, message drafting, quick information retrieval, and personal organization.

## Key Features

- 🌌 Interactive cosmic-themed website interface
- 🤖 Personalized Siri AI assistant
- 🧠 Gemini language model configuration
- 🎙️ ElevenLabs voice selection and voice-agent configuration
- 💬 Conversational question answering
- ✍️ Message drafting and rewriting
- 📝 Quick summaries and everyday assistance
- ⚙️ Configurable agent personality, language, greeting, and behavior

## Technology Stack

- **Website platform:** Hatchable
- **Language model:** Google Gemini (verify the currently active model)
- **Voice technology:** ElevenLabs
- **AI configuration:** System prompts and conversational agent settings

## Agent Personality

Siri is configured to be calm, friendly, concise, professional, and task-focused. Its system prompt defines its responsibilities, communication style, and guardrails.
