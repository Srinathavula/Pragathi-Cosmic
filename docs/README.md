# Pragathi Cosmic Project Documentation

## Project Overview

Pragathi Cosmic is a modern, interactive cosmic-themed website built around a personalized AI voice assistant experience. The project combines a polished web interface with conversational AI, voice interaction, and a warm digital-assistant identity inspired by Siri-style assistance.

The repository is hosted at:
- GitHub: https://github.com/Srinathavula/Pragathi-Cosmic
- Live website: https://pragathi-cosmic.hatchable.site/

## Siri AI Assistant Details

The assistant experience centers on a custom Siri-inspired AI companion that is designed to help with:
- Everyday conversational questions
- Short summaries and concise answers
- Message drafting and rewriting
- Quick information retrieval
- Personalized task assistance

The assistant behavior is intentionally calm, friendly, concise, professional, and task-focused. It is presented as a helpful digital companion with a conversational style that supports productivity and usability.

## Voice Technology

Voice interaction is a central part of the Pragathi Cosmic experience. The project integrates with ElevenLabs-powered voice capabilities to provide an artificial voice assistant experience that complements the conversational AI layer. This supports a richer user experience where the assistant feels more natural and interactive than a text-only interface.

## Technology Stack

The project stack includes:
- Website hosting: Hatchable
- AI conversation model: Google Gemini
- Voice technology: ElevenLabs
- Web interface: Modern, cosmic-themed front-end experience
- AI configuration: System prompts, agent settings, conversational behavior, and assistant personality tuning
